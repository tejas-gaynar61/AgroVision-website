# Task 3 – Documentation, Ignore Rules and Release Tag

## Documentation
The root `README.md` explains the project, setup, features, and Git workflow.

## Ignore rules
`.gitignore` excludes Python virtual environments, bytecode, local environment files, editor settings, and test output.

## Release tag
Create an annotated release tag after merging the tested version into `main`:
`git tag -a v1.0 -m "AgroVision first release"`

Push it with:
`git push origin v1.0`

## Evidence to capture
- `.gitignore` in the repository
- README displayed on GitHub
- GitHub Tags/Releases page showing `v1.0`
